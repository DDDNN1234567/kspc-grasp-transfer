## 三、P0 字段语义的决定性证据

### 3.1 财贸

| 列 | 语义 | V8.1 写入 | 实测 |
|---|---|---|---|
| `ShelfLife` | 桌面保质期 | `max(0,bzDateNum)` | `0000100001` = 150 |
| `UsefulLifeDay` | 线上/手机保质期 | `max(0,bzDateNum)` | `0000100001` = 150 |
| `bBlockNo` | 管理批号 | 固定 0 | 0 |
| `ManSerialNum` | 序列号 | `serialType` 非 0 写 1 | 源全 0，落 0 |

DLL/SQL 旁证：`BaseInfoManage.dll` 的 `UPDATE dbo.ptype SET costmode=3, bBlockNo=1, TakeOut=1`；`AfterSaleService.dll` 的 `p.bBlockNo AS ManageBlockNo`、`p.ManSerialNum AS ManageSerialNO`。

### 3.2 辉煌

官方过程 `p_hh_BascInsertP_Commodity` 第 349 行转调 `p_hh_BasicInsertP`；`p_hh_BasicInsertP` 第 170–184 行只写：

- `UsefulLifeDay ← @LifeDay`
- `SnManCode ← @SnManCode`
- `PJobManCode ← @PJobManCode`

没有 `ShelfLife`、没有 `bBlockNo`。且 `@snManCode` 是中文枚举：

- `不管理 → 0`
- `管理序列号 → 1`
- `仅实物仓库管理 → 2`
- 其它 → 0（传 `'1'` 会静默落 0）
