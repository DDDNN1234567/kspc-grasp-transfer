## 一、结论先行

1. 财贸商品保质期与序列号不是两列，而是四列：`ShelfLife`（桌面保质期）、`UsefulLifeDay`（线上/手机保质期）、`bBlockNo`（管理批号）、`ManSerialNum`（序列号）。
2. 辉煌 TOP15 的商品只有三列需要写：`UsefulLifeDay`、`SNManCode`、`PJobManCode`，没有 `ShelfLife`、没有 `bBlockNo`。
3. 官方过程 `p_hh_BascInsertP_Commodity` 的 `@snManCode` 是中文枚举，不是 `0/1/2` 数字；传 `'1'` 会被 `ELSE` 落 0。
4. 本轮已按上述口径改代码，并在 `财贸测试demo`、`HH15testV4` 两个真实库完成导入/回读。

### 2.2 模板列（商品）

这说明官方模板把“保质期”和“序列号/批号”分开管理，不能用一个 `serialType` 同时表达。

## 三、官方过程穿透

### 3.1 调用链

`p_hh_BascInsertP_Commodity`（LEN 34,165）第 349 行转调 `p_hh_BasicInsertP`。

参数段：

- 第 361 行：`@nLifeDate`
- 第 366 行：`@nsnManCode`
- 第 367 行：`@ipjobCode`

### 3.2 落库段

`p_hh_BasicInsertP` 第 170–184 行 `INSERT INTO [ptype]`：

- `UsefulLifeDay ← @LifeDay`
- `SnManCode ← @SnManCode`
- `PJobManCode ← @PJobManCode`

**全程没有 `ShelfLife`、没有 `bBlockNo`。**

### 3.3 47 个入参（摘录）

`@Parid`、`@FullName`、`@UserCode`、`@Name`、`@NamePy`、`@Type`、`@Standard`、`@Area`、`@CostMode`、`@PtypeType`、`@pooldiscount`、`@btypecode`、`@ppCode`、`@IsWeight`、`@LifeDay`、`@Comment`、`@unit`、`@UCode`、`@SalePrice`、`@PrePrice1`、`@PrePrice2`、`@PrePrice3`、`@SendPrice`、`@BuyDiscountPrice`、`@LowSalePrice`、`@unit1`、`@unitRate1`、`@UCode1`、`@unit1SalePrice`、`@unit1PrePrice1`、`@unit1PrePrice2`、`@unit1PrePrice3`、`@unit2`、`@unitRate2`、`@UCode2`、`@unit2SalePrice`、`@unit2PrePrice1`、`@unit2PrePrice2`、`@unit2PrePrice3`、`@SideUnit`、`@pgManCode`、`@snManCode`、`@kwManCode`、`@Pgholunit`、`@Pgholunitrate`、`@defaulttax`、`@allowprice`、`@pjobmancode`、`@sourcewayzz`、`@sourcewayzzDay`、`@sourcewaywg`、`@sourcewaywgDay`、`@sourcewayww`、`@sourcewaywwDay`。

输出参数：`@RltTypeID`、`@errorValue`。

### 3.4 中文枚举

`@pgManCode`（第 280–283 行）：

- `非管理明细码 → 0`
- `管理明细码 → 1`
- `大码进细码出 → 2`

`@snManCode`（第 285–288 行）：

- `不管理 → 0`
- `管理序列号 → 1`
- `仅实物仓库管理 → 2`
- 其它 → 0

约束：

- 第 289 行：`IF (@nsnManCode=1) AND (@nCostMode NOT IN (0,3,4)) GOTO error6`
- 第 290 行：`IF (@npgManCode=2) AND (@nCostMode IN (1,2)) GOTO error24`

### 3.5 LifeDay 清洗

第 261–267 行：非数字 → 0；>10000 → 10000；<0 → 0。

### 3.6 有效期函数

`f_CountUsefulEndDate(@OutDate,@LifeDay)`：有效期至 = 出库日期 + `LifeDay` - 1；`LifeDay=0` 按 1 计。

## 四、财贸字段语义

| 列 | 语义 | 类型 | V8.1 写入 |
|---|---|---|---|
| `ShelfLife` | 桌面保质期 | `int` | `max(0,bzDateNum)` |
| `UsefulLifeDay` | 线上/手机保质期 | `smallint` | `max(0,bzDateNum)` |
| `bBlockNo` | 管理批号 | `tinyint` | 固定 0 |

- `BaseInfoManage.dll`：`UPDATE dbo.ptype SET costmode=3, bBlockNo=1, TakeOut=1`
- `AfterSaleService.dll`：`p.bBlockNo AS ManageBlockNo`、`p.ManSerialNum AS ManageSerialNO`
- 官方 SQL：`GRASP2HH1500068.sql:3170-3171`、`POSGRASP.sql:975-976/997`
