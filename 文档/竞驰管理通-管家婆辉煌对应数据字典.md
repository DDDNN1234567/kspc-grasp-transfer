## 二、通用树模型（判断归属的核心）

竞驰的四类基本资料（往来单位、商品、仓库、职员）共用同一套树字段，与千业 Bas 高度同构：

| 字段 | 类型 | 语义 | 管家婆对应 |
|---|---|---|---|
| `id` | int identity | 行主键（内部引用键） | 无（管家婆用编号字符串） |
| `par_id` | int | 父行 id，**根 = 0** | 父编号（级联编号前缀） |
| `sonnum` | int | 直接子级数量 | `bsonnum`/`psonnum`/`C1sonnum`/`esonnum` |
| `code` | varchar | 用户自定义编号（可为空/含字母/重复） | `busercode`/`pusercode`/`kusercode`/`eusercode` |
| `fullname` | varchar | 全名（含上级路径语义） | `bfullname`/`pfullname`/`C1fullname`/`efullname` |
| `name` | varchar | 简称 | `bname`/`pname`/`C1name`/`ename` |
| `pym` | varchar | 拼音码 | `bnamepy`/`pnamepy`/`C1namepy`/`enamepy` |
| `del` | int | 0=正常 1=已删除 | `deleted`（导入一律写 0） |
| `isstop` | int | 0=启用 1=停用 | `isStop` |
| `comment` | varchar | 备注 | `bcomment`/`pcomment`/… |
| `orderly` | int | 同级排序 | `RowIndex` |

**层级判定**：不以 `par_id=0` 单判，`T_base_storage_inner` 有独立 `leveal` 列；
往来单位/商品/职员的层级需按 `par_id` 链递归推导（导入器用 BFS 计算）。

#### (4) 分类行

竞驰的商品分类行（`unit1` 为空、`PAR_ID` 指向父分类）在管家婆里必须按"分类"处理：

- 管家婆分类行单位是 **`无`**（`ptype.punitname = '1无'`、`xw_PtypeUnit.Unit1='无'`），
- 直接传空单位会触发官方过程 **`rc=-28 辅助单位1录入的信息有误`**，
- 导入器规则：`unit1` 为空时按 `无` 传入。

## 五、导入规则（实库验证过的硬约束）

### 5.1 官方过程的参数语义是反直觉的（**最容易踩的坑**）

管家婆 `p_hh_BasicInsertB_Commodity` / `p_hh_BascInsertP_Commodity` / `p_hh_BasicInsertK_Commodity` /
`p_hh_BasicInsertE_Commodity` 这四个过程的形参：

| 形参 | **实际语义** | 说明 |
|---|---|---|
| `@FullName` | **编号** | 过程内部用它查 `pusercode` 唯一性、写 `pusercode` |
| `@UserCode` | **全名** | 过程内部 `fn_GetPyCode(@UserCode)` 生成拼音、写 `pfullname` |

因此调用时必须传 `@FullName=竞驰code`、`@UserCode=竞驰fullname`。
传反的后果：管家婆里"编号"列显示商品名、名称列显示编号，且按自定义编号反查全部失效。

### 5.2 父引用必须用官方过程返回的树编号

官方过程按库内现有行数续排编号（如库里已有 883 个单位时，新单位是 `00017`、`00018`），
**不是**我们预期的 `00001` 行序。子级 `ParId` 必须使用过程 `OUTPUT @rt` 返回的实际树编号，
否则报 `rc=-17 没有找到父类`（单位）/`rc=-3 父类仓库不存在` / `rc=-5 父类商品不存在`。

### 5.3 期初数据需要"未开账"状态

`sysdata.iniover=1`（已开账）时，官方过程拒收期初应收应付（`rc=-13`）、库存期初。
导入器做法：导入前把 `iniover` 置 0，`try/finally` 结束后恢复原值。

### 5.4 辅助单位与换算率必须同进同退

官方过程校验（实测）：
- 辅助单位名非空但换算率为空或非数字 → `error28`（rc=-28）
- 辅助单位名为空但换算率非空 → 同样 `error28`

竞驰空值常以 `0` 落库，`_s(0)` 会得到字符串 `"0"`（非空）→ 触发报错。
导入器规则：`unit2` 为空或换算率为 `0` 时，两者同时清空。

### 5.5 仓库必须平铺

见 3.2：带子级的仓库在管家婆里是"类仓库"，不能挂库存（rc=-7）。

### 5.6 商品分类单位写"无"

见 3.4(4)。

### 5.7 导入后必须归位

- 四张主表 `updatetag = 10000`（低于此值客户端增量过滤会整棵树的节点消失）
- `xw_BaseUpdateTag.UpdateTag = 0`
